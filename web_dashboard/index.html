 About AeroSense Pro

AeroSense Pro is an offline-first Edge AI air quality platform built on the Arduino UNO Q heterogeneous dual-core computing platform.


Rather than streaming raw bytes to expensive cloud platforms, AeroSense performs deterministic stoichiometric source attribution and 6-hour predictive forecasting directly on the device with zero cloud recurring cost.


Key Technical Highlights:

  • Zero Cloud Cost ($0.00/yr): Air-gapped autonomy for schools, RWAs, and municipal wards.
  • Heterogeneous Dual-Compute: Microsecond I/O acquisition on STM32U585 + Linux AI inference on Qualcomm QRB2210.
  • Stoichiometric Domain Classification: Distinguishes traffic diesel exhaust from trash fires, kitchen fumes, and dust.
  • Gorilla Compression: 89.8% - 95.7% bandwidth reduction for battery-powered mesh nodes.

The STM32U585 MCU polls sensors deterministically via direct memory access (DMA), then sends structured binary frames to the Qualcomm QRB2210 Linux MPU across the high-speed virtual UART bridge (115200 baud).
